# P3c-10.7 技术调试记录

## 零更新浮点等价

预期复制前两层及 pre-Tanh 均值头后，在原 43 维标准化和一次 Tanh 下，乘 .25 的动作逐项与蒸馏策略一致。首次工程运行在首个动作发现最大差 1.2573e−8，三个分量均不同，零交互、零更新，触发等价断言。日志和部分产物在 `outputs/p3c-10.7/initial-parity-failure.log` 与同名目录。假设是 SB3 对原本对称归一化动作额外执行 affine unscale，加上单条样本的批量 linear 与原 unbatched kernel 数值顺序不同。将该对称动作空间的缩放实现为恒等，单样本确定性预测用原一维 kernel。两项一起验证，未单独量化各自贡献。修订后完整 62 回合动作严格一致，按解压内容比对的逐步 JSONL 完全一致。

## 预热触发饱和保护

种子 11 的首个在线场景为 18010 凸起朝向。预期 500 步初始化策略附近的高斯探索。实际在第 211 步，末 50 步增益前 X 轴绝对值 ≥.95 的比例达到 52%，首次越过预注册的 50% 门槛。Y/Z 为 0%/6%，有符号和绝对账本均在保护范围。回放保存动作并在同一在线访问状态计算未更新的确定性 actor，末窗比例为 54%/0%/6%，所以现有饱和不能归因于梯度更新，也无证据表明随机探索是其唯一来源。乘 .25 后执行接口的对应饱和为零。该保护门槛监测 SAC 概率空间，执行动作受增益限制；是否应结合初始化参考的增量监测饱和需另行审议。本轮保持原门槛和停止结论。

触发保护后，预期写入停止快照。实际 SB3 试图 pickle 当时挂在模型上的更新日志写入流，报错留下 0 字节 zip，未完成停止点确定性复评和常规 Replay Buffer 保存。`run.log` 和在线日志保留。已从模型序列化字段排除流，并通过带写流的 checkpoint 保存/重载测试。另将 Actor optimizer 构造迁到 `_setup_model`，保证冻结参考不进入 optimizer 且载入的参数组一致。由于 211 步尚未到 warm-up 更新门槛，0 步可加载权重与停止点 Actor/Critic 权重等价，标记为重建快照。回放 211 条动作，逐步目标及实测 TCP 日志精确匹配，重建分析用 buffer；它不是原训练进程的断点。修复未触发新一轮在线训练。
