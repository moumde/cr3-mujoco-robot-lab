# P5a-R3 技术记录

- 封存清单保存的是种子组与原采样机制。用原 P3c-7 sampler 展开双朝向，记录清单来源哈希，未用新的抽样替代。
- 正式目录创建采用排他方式。若目录已存在，运行入口退出。每个策略每个场景只推进一次。所有候选启动前重新校验文件哈希。推理只用已冻结模型，未调用训练与 Replay。
- 渲染阶段使用正式回合输出的完整积分状态快照，前向更新可视模型，不重新执行策略或推进物理。每五步截取一帧，并保存终点。并排视频较早结束的策略保持最终画面。
- 所有回合步数、成功回合步数和共同成功上的配对差异分别统计。统计以三个训练种子的均值和范围为主，未把同 XY 双朝向当作独立样本来估计置信区间。
