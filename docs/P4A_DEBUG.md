# P4a 技术调试与 P3c-10.7-R1 归档

## 连续物理接管

初始接口差异是 P2b 和 Grasp & Lift 都持有自己的 reset 入口。若分别调用，将替换物体状态。实际修改为共享 `MjModel/MjData`，P2b 完成唯一 reset 和视觉定位后，学习环境仅初始化目标和账本。接管以实际关节、TCP 与夹爪为准，复用已有运动规划。单测验证附接前后 qpos、qvel、ctrl、time 完全一致，随后在同一实例推进一个周期。固定双朝向通过后再进入随机面板，44 回合均完成。实测名义与实际工具内偏差最大 8.25 mm，记录只供评分。仍无法从 RGB 获得在手实时位姿，后续若移除特权观测需单独验证感知和握持估计。

## 冻结 SAC 研究结果

[P3c-10.7 调试](P3C_10_7_DEBUG.md)记录初始等价约 1.26e−8 浮点差、对称动作复缩放及单样本矩阵路径修复、写入流导致停止 checkpoint 序列化失败及其修复。原试验 211 步误触发饱和保护，0 次更新。[R1 报告](P3C_10_7_R1.md)记录 750 步 62 次更新，开发 42/42、留出 20/20，完成步数平均减少 4.55/4.45，三个平面朝向回合触及 5 mm Y 累计审查线，按预注册规则停止。750 步策略继续保留为研究成果，独立 Test 仍封存。
