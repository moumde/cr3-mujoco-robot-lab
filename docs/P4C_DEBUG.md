# P4c 技术调试记录

- 50 Hz 指令和 10 FPS 图像以整数控制索引对齐。部署每 100 ms 捕获双路视觉、本体状态并预测五条目标，每条执行 20 ms。动作存储与回放均在含重力前馈且已限幅的 actuator 目标空间。部署只应用真实控制器范围约束，不重复加重力偏置或重复做夹爪渐进限速。
- 扩展数据采集进程在保存前 32 个回合后出现 EGL/MuJoCo 段错误，原日志保留。余下三个预注册 seed 5516–5518 在新进程接续，附加清单与数据；没有改种子、任务或提交筛选。段错误的具体底层原因未定位。
- 模型仅看实时 RGB 与 20 维机器人状态。分析可读物体真值和接触，闭环动作生成不使用这些字段。阶段时钟取训练示范的按阶段中位起始步，仅供统一评分与定位失败；时钟进入阶段并不证明策略已经完成对应物理事件。
- NVIDIA 驱动不可用，本轮用 CPU 训练和推理，提供 CUDA 参数入口。峰值显存、RTX 5060 吞吐未实测。
- LeRobot 0.7.0 将形状为 (1,) 的整数阶段特征在 Parquet 解码成标量。第一次离线校验比较了单元素列表，因形状断言退出。校验改为标量后，逐行复核 8,187 个动作片段、状态与时间戳全部通过，未修改导出数据或监督标签。
