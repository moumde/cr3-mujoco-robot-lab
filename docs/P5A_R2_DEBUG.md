# P5a-R2 技术调试记录

- 同 seed 的两算法共享按序回合初始种子与朝向。策略造成终止长度变化时，训练场景消耗位置按回合推进。验证环境独立，避免评估推进训练队列。
- PPO 使用带 Tanh Jacobian 的原概率路径，仍由 SB3 收集 rollout、计算超时 bootstrap 及 GAE。新训练子类只在原 clipped surrogate 目标叠加 .05 的确定性动作参考 MSE。SAC 沿用相同形式的参考损失及软目标。PPO 与 SAC 的 entropy、方差架构、优化步数不同。
- 零更新六组全部在 62 场景逐步动作相同。训练过程中均记录相同状态上的确定性参考漂移、采样动作及投影后目标差。评估文件单独保留所有失败。跨阈值审查影响候选筛选，原历史实验的早停解释保持。
- 早期 SAC seed 22 在 1k 为 36/42、16/20，5k 恢复到 42/42 与 20/20。seed 11 继续出现后续退化，说明训练回报或早期恢复均不能替代闭环检查。
